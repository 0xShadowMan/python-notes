# Chapter 3 - Strings

## Overview
This chapter covers string basics in Python, including slicing, string methods, escape sequences, and simple string-based exercises.

## Files
- `01_intro_to_string.py`
  - Demonstrates basic string slicing.
- `02_negative_slicing.py`
  - Shows positive and negative slicing examples.
- `03_str_functions.py`
  - Uses string methods like `len()`, `endswith()`, `startswith()`, `capitalize()`, `upper()`, `lower()`, `replace()`, `find()`, `count()`, and `title()`.
- `04_escape_seq.py`
  - Demonstrates escape sequences `\n`, `\t`, and escaped quotes.

## Problems
The `Problems/` folder contains practice exercises:

- `01_Problem.py`
  - Prompts for a name and prints a greeting.
- `02_Problem.py`
  - Builds a formatted letter using f-strings and demonstrates `replace()`.
- `03_Problem.py`
  - Detects double spaces in a string using `find()`.
- `04_Problem.py`
  - Replaces double spaces with a single space.
- `05_Problem.py`
  - Prints a formatted letter with newlines and tabs.

## Key Concepts
- Strings are sequences of characters and support slicing.
- Negative indexing accesses characters from the end.
- String methods help inspect and modify strings.
- Escape sequences add newlines, tabs, or quotes inside strings.
- `f-strings` make string formatting easier.

## Usage
Run examples in the chapter folder:
- `python 01_intro_to_string.py`
- `python 02_negative_slicing.py`
- `python 03_str_functions.py`
- `python 04_escape_seq.py`
- `python Problems\01_Problem.py`
- `python Problems\02_Problem.py`
- `python Problems\03_Problem.py`
- `python Problems\04_Problem.py`
- `python Problems\05_Problem.py`

## Notes
- `Problems/01_Problem.py` and `Problems/02_Problem.py` require interactive input.
- Use string methods and slicing to solve string manipulation tasks efficiently.
