# Chapter 8 - Functions & Recursions

## Overview
This chapter covers Python functions and recursion, including function definition, arguments, return values, default arguments, and recursive function calls.

## Files
- `01_functions.py`
  - Introduces function definition, function calls, and a small menu-driven example.
- `02_Quick_quiz.py`
  - Demonstrates a function using an external variable and conditional function invocation.
- `03_functions_with_arguments.py`
  - Shows passing arguments to a function and printing a return value.
- `03_functions_with_arguments_exta.py`
  - Demonstrates functions with multiple arguments and user input.
- `04_defualt_argument.py`
  - Shows default argument values in function definitions.
- `05_recursions.py`
  - Demonstrates recursion by computing a factorial using a recursive function.
- `06_return.py`
  - Explains `return` values and how to capture them in variables.
- `arguments.txt`
  - Describes what arguments are and how they are used when calling functions.
- `Best Use Of Functions.py`
  - Example of organizing tasks into multiple functions in a menu-driven program.

## Problems
The `Problems/` folder contains function practice exercises:

- `01_Problem.py`
  - Finds the greatest of three numbers using a function.
- `02_Problem.py`
  - Converts Celsius to Fahrenheit using a function that returns a value.
- `03_Problem.py`
  - Demonstrates using `print(..., end="")` to control printing behavior.
- `04_Problem.py`
  - Uses recursion to calculate the sum of the first `n` natural numbers.
- `05_problem.py`
  - Prints a descending star pattern using recursion.
- `06_Problem.py`
  - Converts inches to centimeters using a function.
- `07_Problem.py`
  - Removes a given word from a list while stripping the same word.
- `08_Problem.py`
  - Prints a multiplication table using a function.

## Key Concepts
- Define reusable code with `def function_name(parameters):`.
- Call functions with positional arguments and receive results using `return`.
- Default arguments allow functions to be called with fewer parameters.
- Recursion occurs when a function calls itself and requires a base case to stop.
- Modular programs organize logic into multiple functions for clarity and reuse.
