# Chapter 7 - Loops in Python

## Overview
This chapter covers loop constructs in Python, including `for` loops, `while` loops, `for...else`, `break`, `continue`, and `pass`.

## Files
- `01_loops.py`
  - Introduces loops by comparing repeated print statements with a `for` loop.
- `02_while_loops.py`
  - Demonstrates a `while` loop that repeats until the condition becomes false.
- `03_list_using_while.py`
  - Iterates over a list using a `while` loop and an index.
- `04_for_loops.py`
  - Shows a basic `for` loop with `range()`.
- `05_for_loop_iterate.py`
  - Iterates over a list, tuple, and string using `for`.
- `06_for_loop_with_else.py`
  - Demonstrates the `else` block on a `for` loop.
- `07_break_and_continue.py`
  - Demonstrates `break` and `continue` inside loops.
- `08_pass.py`
  - Shows the `pass` statement as an empty block placeholder.
- `note.txt`
  - Contains a chapter summary and a brief loop flow diagram.

## Key Concepts
- Use `for` loops for fixed-range or sequence-based iteration.
- Use `while` loops when repetition depends on a changing condition.
- `break` exits the loop immediately.
- `continue` skips the current iteration.
- `pass` is a placeholder for empty loop bodies.
- `for...else` runs the `else` block when the loop completes normally.
