Chapter 4: Lists and Tuples

Lists
- List are mutable
- A list is an ordered, mutable collection defined with square brackets: [ ]
- Lists can contain mixed data types, including strings, numbers, booleans, and other lists.
- You can access elements by index: list[0], list[1], etc.
- You can modify list elements by assignment: list[0] = "new value"

Common list methods shown in Chapter 4:
- append(value): Add value to the end of the list.
- insert(index, value): Insert value at the given position.
- remove(value): Remove the first matching value.
- pop(): Remove and return the last item.
- sort(): Sort the list in place.
- reverse(): Reverse the order of the list.
- index(value): Return the first index of value.

Tuples
- Tuples are immutable
- A tuple is an ordered, immutable collection defined with parentheses: ( )
- Once a tuple is created, its values cannot be changed.
- Use a trailing comma for a one-element tuple: (1,)
- Tuples are useful for fixed groups of values and can be more efficient than lists for constant data.
