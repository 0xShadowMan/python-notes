# Chapter 2 - Variables and Data Types

## Overview
This chapter introduces Python variables, naming rules, common data types, the `type()` function, operators, and user input.

## Files
- `01_veriable.py`
  - Defines variables, prints values, and demonstrates type conversion using `str()`.
- `02_datatype.py`
  - Shows examples of `int`, `float`, `str`, `bool`, and `NoneType`.
- `03_rule_variable.py`
  - Demonstrates valid variable names and comments about invalid names.
- `04_operators.py`
  - Demonstrates arithmetic, comparison, logical, assignment, and bitwise operators.
- `05_type.py`
  - Demonstrates using `type()` to inspect Python variable data types.
- `06_input.py`
  - Shows how to read user input, convert it to integers, and calculate a sum.
- `note.txt`
  - Contains a chapter summary on variables, naming rules, data types, `type()`, and `input()`.

## Key Concepts
- Variables store data values in Python.
- Variable names must start with a letter or underscore and may only contain letters, numbers, and underscores.
- Common data types include `int`, `float`, `str`, `bool`, and `NoneType`.
- Use `type()` to inspect a variable's type.
- Use `input()` to get values from the user, and convert them with `int()`, `float()`, or `bool()` as needed.
