# Chapter 4 - Lists and Tuples

## Overview
This chapter covers Python lists and tuples, including how lists are mutable, common list methods, and tuple immutability.

## Files
- `01_list.py`
  - Demonstrates list creation, element access, and modifying list values.
- `02_list_methods.py`
  - Shows list methods like `append()`, `sort()`, `remove()`, `pop()`, `index()`, and `insert()`.
- `03_tuples.py`
  - Demonstrates tuple creation and shows that tuples are immutable.
- `note.txt`
  - Contains chapter notes on list and tuple characteristics and common operations.

## Problems
The `Problems/` folder contains practice exercises:

- `01_problem.py`
  - Collects seven fruits from the user and stores them in a list.
- `02_Problem.py`
  - Reads marks for six students and stores them in a list.
- `03_Problem.py`
  - Demonstrates that tuples cannot be modified after creation.
- `04_problem.py`
  - Calculates the sum of values in a list using `sum()`.
- `05_problem.py`
  - Counts the number of zeros in a tuple using `count()`.

## Key Concepts
- Lists are ordered and mutable.
- Tuples are ordered and immutable.
- Lists support in-place modification and many built-in methods.
- Use tuples when values should not change after creation.

## Usage
Run examples from the chapter folder:
- `python 01_list.py`
- `python 02_list_methods.py`
- `python 03_tuples.py`
- `python Problems\01_problem.py`
- `python Problems\02_Problem.py`
- `python Problems\03_Problem.py`
- `python Problems\04_problem.py`
- `python Problems\05_problem.py`

## Notes
- Use `[]` to create lists and `()` to create tuples.
- A one-element tuple requires a comma, e.g. `(1,)`.
