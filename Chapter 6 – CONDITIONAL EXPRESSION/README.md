# Chapter 6 - Conditional Expressions

## Overview
This chapter covers conditional statements in Python, including `if`, `elif`, and `else` for branching logic.

## Files
- `01_conditionals.py`
  - Demonstrates a simple `if` / `elif` / `else` statement checking age categories.
- `02_if_elif_else_ladder.py`
  - Shows an `if` / `elif` / `else` ladder with age validation and multiple branches.
- `03_multiple_if_statements.py`
  - Combines separate `if` statements with an `elif` chain for additional logic.
- `note.txt`
  - Contains a short chapter description about `if..elif..else` statements.

The `Problems/` folder contains practice examples for conditional logic:

## Key Concepts
- `if` evaluates a condition and executes code when it is `True`.
- `elif` checks additional conditions when previous `if`/`elif` branches are `False`.
- `else` handles the final fallback case when no previous conditions match.
- Use boolean operators like `and`, `or`, and `not` to combine conditions.
- Conditional logic is useful for input validation, comparisons, and decision-making.
